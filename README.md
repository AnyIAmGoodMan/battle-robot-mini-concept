# Mini Battle Robot Concept

Статус: Инженерная концепция (Concept Design).

Проект разрабатывался для участия в соревнованиях по робототехнике в категории "Мини" (до 1.5 кг). 
Был выполнен этап проектирования механической части (CAD-чертежи), составлена электрическая схема управления и спецификация компонентов. 
До этапа сборки и реализации проект не дошёл.

---

1. Концепция

Цель проекта — разработка боевого робота с активным оружием в виде вращающегося диска (циркулярной пилы).

Основные конструктивные решения:
- Низкий профиль для устойчивости.
- Дифференциальный привод (2 задних колеса).
- Переднее управляемое колесо на сервоприводе.
- Активное оружие — диск диаметром 200 мм с зубьями.
- Управление на базе платформы Arduino.

---

2. Механическая часть

Конструкция робота состоит из трёх основных частей, спроектированных в CAD-системе:

- Body Part 1 — нижнее шасси (крепление колёс, двигателей и аккумулятора).
- Body Part 2 — центральный каркас (крепление оружия и электроники).
- Body Part 3 — верхний кожух (защита Arduino и драйверов).

Оружие: алюминиевый диск диаметром 200 мм с зубьями. Привод — бесколлекторный мотор (BLDC) через систему шестерён.

Ходовая часть:
- 2 ведущих задних колеса (дифференциальный привод).
- 1 переднее управляемое колесо (поворот через сервопривод MG995).

Все CAD-чертежи доступны в папке /cad.

---

3. Электрическая схема

Управление реализовано на базе микроконтроллера Arduino Nano 33 IoT.

Структура подключения:
- Arduino -> L298N (драйвер ходовых моторов).
- Arduino -> ESC (регулятор скорости для BLDC мотора оружия).
- Arduino -> MG995 (сервопривод управляемого колеса).

Схема подключения представлена в папке /schematics.

5. Что было сделано

- Разработаны CAD-чертежи корпуса, диска оружия и шестерни.
- Составлена электрическая схема подключения компонентов.
- Составлена спецификация механических и электрических компонентов.

---

6. Почему проект не был реализован

Проект был заморожен на этапе проектирования по следующим причинам:
- Отсутствие бюджета на изготовление алюминиевых деталей и закупку компонентов.
- Сложность изготовления диска оружия (требовалась токарно-фрезерная обработка на заказ).
- Дисквалификация команды с турнира

На данный момент проект не имеет рабочего прототипа и не проходил испытаний.
